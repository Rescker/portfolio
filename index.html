01 / Trabalho Projetos públicos

  1. O problema

    Editar config.cpp para montar diálogos de Arma 3 é escrever à mão coordenadas num sistema de grid que ninguém consegue visualizar.

    O que construí

    Canvas com arrastar, redimensionar e zoom, guias de alinhamento, seleção múltipla, undo/redo com coalescência de 200 ms e 51 presets de componentes. Suporta os três sistemas de coordenadas — GUI_GRID, SafeZone e absoluto — com import/export de config respeitando herança.

    Stack

    • TypeScript
    • React 18
    • Zustand
    • Vite
    • Tailwind
    • Monaco

    Abrir o editor Código no GitHub

  2. O problema

    Sessões de agente vivem no terminal. Acompanhar um turno longo do celular significa ou perder o progresso, ou abrir um cliente SSH.

    O que construí

    Ponte por long-polling entre o Telegram e uma sessão local via NDJSON sobre stdin/stdout. Cada turno vira no máximo duas mensagens: a resposta, editada conforme o texto chega, e uma linha de atividade que lista as chamadas de ferramenta. Comandos de shell ficam atrás de botões Aprovar/Negar; mensagens no meio do turno entram como steering.

    Stack

    • Python
    • asyncio
    • python-telegram-bot
    • JSON-RPC

    Código no GitHub

02 / Sobre Brasil · GMT−3

A solução mais curta
é a que a pessoa entende.

Gosto de software prático e intuitivo: a ideia é sanar o problema, não exibir a solução. Isso decide arquitetura, tela e até o que eu deixo de construir.

No back-end trabalho com Spring Boot, PostgreSQL, MySQL e MongoDB, com Docker no caminho até produção. No front, React com Vite e Tailwind, TypeScript sem atalhos e atenção real a performance e acessibilidade.

Gosto de ferramentas que resolvem um problema meu primeiro. O A3L GUI Editor nasceu de editar config.cpp à mão; o telegram-coder, de querer acompanhar um turno de agente sem abrir o terminal.
